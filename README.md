# TallyVoice.ai marketing website

Responsive single-page SaaS website for TallyVoice.ai.

## Files

- `index.html` main page
- `styles.css` responsive design
- `script.js` mobile menu, question demo and early-access form interaction
- `favicon.svg` brand icon

## Run locally

Open `index.html` in a browser, or run a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before launch

- Connect the early-access form to your CRM, email platform or backend.
- Replace planned pricing after customer validation.
- Add Privacy Policy and Terms pages.
- Complete QuickBooks and Xero partner approval before using official marketplace badges.
